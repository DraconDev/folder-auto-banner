# Goal Prompt

Add a custom program argument to numbered navigation: `f N ACTION` opens item N with the specified program (e.g., `f 4 krita`, `f 4 ranger`, `f 4 cat`). Without ACTION, default behavior is unchanged (cd for dirs, editor for files).

## What changes

### New feature
- `f N ACTION` — open item N with `ACTION` instead of the default behavior
- Works for both files and directories (user's responsibility if the app doesn't handle it)
- Examples: `f 4 krita`, `f 4 ranger`, `f 4 cat`, `f 4 code`

### Unchanged behavior
- `f N` (no action arg) — cd if directory, open in editor if file (identical to current)
- `f` (no args) — banner display
- `f --edit N` — force open in editor (new flag for clarity)
- `f --run N` — force run the file directly (new flag for clarity)

## Files to modify
1. `src/cli/mod.rs` — add `--edit`/`--run` flags and second positional arg to `navigate_by_number`
2. `src/cmd/banner.rs` — update `navigate_by_number()` to accept optional app action
3. `fab-shell.bash` and `fab-shell.zsh` — pass through action arg and flags

## Verification
- `f 4 cat` → runs `cat /path/to/item4`
- `f 4` (on file) → opens in editor
- `f 4` (on dir) → cd into dir
- `f 4 ranger` on dir → runs `ranger /path/to/dir`
- `f 4 --edit` → opens in editor (overrides default)
- `f 4 --run` → runs the file directly
- All existing unit tests + integration tests still pass
